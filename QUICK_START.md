# 🚀 Quick Start - TBEE Platform

## Test rapide en 3 étapes

### 1️⃣ Tester l'espace ÉTUDIANT

**Connexion** : Utilisez n'importe quel email **SANS** "admin"  
Exemple : `etudiant@exemple.fr` + n'importe quel mot de passe

**Parcours recommandé** :
1. 📊 **Dashboard** → Voir progression, stats et modules
2. 📚 **Mes modules** → Explorer les 6 modules, cliquer sur un module
3. 🎥 **Détail module** → Regarder une vidéo (YouTube)
4. 📄 **Mon CV** → Upload un PDF, voir le feedback
5. 💼 **Cas pratiques** → Faire un exercice interactif
6. 👤 **Mon profil** ⭐ NOUVEAU :
   - Modifier vos informations (mode édition)
   - Gérer votre reconnaissance RQTH
   - Configurer vos notifications

### 2️⃣ Tester l'espace ADMIN

**Connexion** : Utilisez un email **AVEC** "admin"  
Exemple : `admin@tbee.fr` + n'importe quel mot de passe

**Parcours recommandé** :
1. 📊 **Vue d'ensemble** → Stats globales, tableau étudiants
2. 👥 **Gestion utilisateurs** → Rechercher, filtrer, voir détails
3. 📈 **Suivi personnalisé** → Voir profil complet d'un étudiant, ajouter une note
4. ⚙️ **Paramètres** ⭐ NOUVEAU :
   - **Debug** : Activer le mode, voir les logs colorés 🛠️
   - **Système** : Consulter les infos serveur, monitoring 💾
   - **Modules** : Gérer les 6 modules
   - **Utilisateurs** : Voir les rôles et permissions

### 3️⃣ Tester le RESPONSIVE

**Sur mobile (390px)** :
- Cliquez sur le **menu hamburger** (☰) en haut à gauche
- Naviguez dans la sidebar (overlay)
- Testez les tableaux et grids (1 colonne)
- Vérifiez que tout est lisible et utilisable

**Sur desktop (1440px)** :
- Sidebar toujours visible à gauche
- Grids en 4 colonnes
- Tous les détails des tableaux visibles
