Ce script va tester votre connexion Supabase étape par étape.

Test 2 : Inscription

Test 3 : Récupérer le profil

📜 SCRIPT SQL - CONFIGURATION SUPABASE

Si des erreurs persistent, exécutez ce script dans Supabase SQL Editor :

-- ========================================
-- SCRIPT COMPLET DE CONFIGURATION TBEE
-- ========================================

-- 1. Créer la table profiles (si elle n'existe pas)
CREATE TABLE IF NOT EXISTS public.profiles (
    id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
    email TEXT NOT NULL,
    first_name TEXT,
    last_name TEXT,
    role TEXT NOT NULL DEFAULT 'student' CHECK (role IN ('student', 'admin')),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Activer Row Level Security
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;

-- 3. Supprimer les anciennes politiques (au cas où)
DROP POLICY IF EXISTS "Users can view own profile" ON public.profiles;
DROP POLICY IF EXISTS "Users can update own profile" ON public.profiles;
DROP POLICY IF EXISTS "Enable insert for authenticated users only" ON public.profiles;

-- 4. Créer les nouvelles politiques (PERMISSIVES)
CREATE POLICY "Users can view own profile"
    ON public.profiles FOR SELECT
    USING (auth.uid() = id);

CREATE POLICY "Users can update own profile"
    ON public.profiles FOR UPDATE
    USING (auth.uid() = id);

CREATE POLICY "Enable insert for authenticated users only"
    ON public.profiles FOR INSERT
    WITH CHECK (auth.uid() = id);

-- 5. Créer le trigger pour auto-créer les profils
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS TRIGGER AS $$
BEGIN
    INSERT INTO public.profiles (id, email, first_name, last_name, role)
    VALUES (
        NEW.id,
        NEW.email,
        COALESCE(NEW.raw_user_meta_data->>'first_name', ''),
        COALESCE(NEW.raw_user_meta_data->>'last_name', ''),
        COALESCE(NEW.raw_user_meta_data->>'role', 'student')
    );
    RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

-- 6. Activer le trigger
DROP TRIGGER IF EXISTS on_auth_user_created ON auth.users;
CREATE TRIGGER on_auth_user_created
    AFTER INSERT ON auth.users
    FOR EACH ROW
    EXECUTE FUNCTION public.handle_new_user();

-- 7. Vérifier que tout fonctionne
SELECT 'Configuration terminée !' AS status;

🆘 GUIDE DE DÉPANNAGE

❌ Erreur : "Table profiles not found"

Cause : La table n'existe pas dans Supabase

Solution : Exécutez le script SQL ci-dessus dans Supabase → SQL Editor

❌ Erreur : "new row violates row-level security policy"

Cause : Les politiques RLS bloquent l'accès

Solution : Exécutez les étapes 3-4 du script SQL (politiques RLS)

❌ Profil non créé après inscription

Cause : Le trigger n'est pas activé

Solution : Exécutez les étapes 5-6 du script SQL (trigger)

❌ Variables d'environnement non trouvées

Cause : Le fichier .env.local n'est pas au bon endroit ou mal nommé

Solution :

  1. Créez le fichier .env.local à la RACINE du projet (même niveau que package.json)
  2. Pas d'espace dans le nom : .env.local (pas .env .local)
  3. Redémarrez le serveur : Ctrl+C puis npm run dev
